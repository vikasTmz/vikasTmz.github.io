Experiments with coding agents to produce expressive, compact, and editable 3D scenes.

In the above examples, we give the agent a mesh (typically scanned), and ask it to approximate the geometry, appearance, and motion using analytic primitives, parametric curves and surfaces, and procedural functions. The agent accounts for user desired edits when generating these editable, structured shape representations. It exposes interpretable parameter(s) to facilitate edits.
